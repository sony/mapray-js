# @mapray/ui

This fork ships release tarballs on GitHub Releases instead of publishing to npm.

## Installation

Install `@mapray/mapray-js` first, or install both tarballs together:

```sh
npm install \
  https://github.com/TakamuneSuda/mapray-js/releases/download/v0.9.5/mapray-js.tgz \
  https://github.com/TakamuneSuda/mapray-js/releases/download/v0.9.5/mapray-ui.tgz
```
